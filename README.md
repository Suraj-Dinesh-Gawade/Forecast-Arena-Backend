This is the server-side infrastructure for the Forecast Arena prediction platform. It handles authentication, market data, transaction logs, and real-time odds calculation.

Key Features

Admin Command Center: Manage active markets, resolve questions, and settle payouts for winners.

Market Logic: Automated calculation of dynamic odds and user balance updates.

Security: Hashed authentication and user suspension system for policy enforcement.

Tech Stack

Runtime: Node.js, Express.

Database: MySQL.

Dependencies: bcrypt (password hashing), mysql2 (database driver).
